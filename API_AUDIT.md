# API limits, terms, and fallback audit

**Reviewed:** 2026-10-04
**Scope of this pass:** DEX search, DEX pool/quote lookups, DEX OHLCV, and the DEX-heat card. This is an engineering review, not legal advice. Provider limits, terms, geographic reach, CORS behavior, schemas, and uptime can change without notice.

## Changes made in this pass

1. **Reduced DEX search fan-out.** Text search now calls DEX Screener first and only calls GeckoTerminal if the primary search fails or returns no pools. Address lookup no longer spends up to two additional GeckoTerminal calls to enrich an already-successful result. GeckoTerminal remains an independent fallback on a miss.
2. **Reduced DEX Heat from four GeckoTerminal calls to one.** It now uses the documented all-networks `GET /networks/trending_pools` route and reads the network relationship in each pool. DexScreener boosts still load independently. If GeckoTerminal is unavailable, the store retains its last usable snapshot and the boosts can still populate the card.
3. **Added a best-effort local request budget.** The shared transport caps GeckoTerminal at **8 requests per 60 seconds** per browser origin, leaving headroom under its approximate 10/minute public cap. Recent call timestamps are shared across same-origin tabs through `localStorage` when available; storage failure degrades to a per-tab in-memory limit. A local skip is not misreported as an upstream HTTP 429 and does not open the app-wide cooldown overlay; DEX chart refresh waits for the returned retry window. `npm run api:budget-smoke` verifies the eight-call cap, local ninth-call rejection, storage stamps, and unaffected sources.
4. **Aligned response cache TTLs to the documented one-minute upstream cache.** GeckoTerminal pool/search/OHLCV calls are cached for 60 seconds in memory and remain in-flight deduped.
5. **Removed GeckoTerminal response persistence in localStorage.** DEX quote/candle UI state still retains the last successful value in memory while the page is open; a reload may require a fresh provider response. This avoids storing GeckoTerminal responses unencrypted in browser storage.
6. **Pinned the documented GeckoTerminal API version** with `Accept: application/json;version=20230203` instead of following an unannounced latest schema.
7. **Added source attribution** for GeckoTerminal/CoinGecko in DEX search rows, DEX charts, and the on-chain/global panels; the chart and panels link to the provider sites.

## Limits of the implementation

- The 8/minute budget is **per browser origin**, not a globally shared quota for all visitors behind an IP, and cannot account for unrelated traffic using the same upstream IP. It reduces avoidable calls; it cannot guarantee that a shared-IP provider limit is never reached.
- These changes do not bypass provider rate limits, regional/WAF blocks, unsupported tokens, or source outages. On failure, existing data is retained in memory where available; otherwise the feature degrades to fewer/no DEX results.
- The live DEX smoke could not verify provider responses from this sandbox: searches returned no DEX pools and the local GeckoTerminal budget engaged before the direct-provider checks completed. A browser/CORS and regional matrix remains open; no claim is made that a provider is reachable from every country or network.
- DEX Screener's competing-product wording needs owner/legal review before increasing reliance. DexPaprika remains a candidate only if its public-app display rights are confirmed.

### Narrow changes made in this slice

1. Added a **PublicNode gas-price-only fallback** for the four Blockscout chains; rows retain partial fields and visibly identify source/mixed provenance.
2. Removed a derivatives unit assumption: Gate `open_interest` is a contract count, so only an explicit USD-notional value is accepted. Funding annualisation now uses the reported Gate interval or OKX funding timestamps and stays blank if unavailable.
3. Ticker 24 h change fields remain `null` when the provider omits them. Heatmap tiles use a neutral style, breadth counts only known changes, and screener CSV/sorts preserve unknowns. An empty CVD session is no longer shown as zero.
4. Exchange probes are now described as **best-effort HTTP fetches or WebSocket opening handshakes**, not verified reachability/real latency. A 429 is not ranked as a healthy slow response. UI text no longer claims a probe of “all {count} exchanges” guarantees reachability; stored results can be up to 6 h old.
5. Removed the screener's unverified “~2,000 pairs / entire market” claims from README and localized copy; attribution and current source are surfaced in the heatmap/breadth/screener UI. Coverage copy now distinguishes the configured 33 canonical chain IDs/aliases from live provider support.
6. The dependency audit found a critical Next.js `next/og` advisory on 16.3.4. Next.js and `eslint-config-next` were updated to 16.3.8, and Wrangler from 4.130.0 to 4.147.0. A non-forced `npm audit fix` patched `ip-address` and `brace-expansion`; Puppeteer was upgraded to 25.12.0, removing its browser-download/proxy/zip findings. The unused `tailwindcss-animate` plugin was removed after confirming none of its utility classes are used. `npm audit --omit=dev` reports zero production-dependency findings; the full tree now reports 7 high dev/transitive findings in the Tailwind/ESLint glob-brace chain. Puppeteer 25 requires Node ≥22.12 for browser QA. No `--force` downgrade was applied.
7. Replaced `next/font/google` with local Fontsource variable-font packages so production builds no longer need `fonts.googleapis.com`. Both `npm run build` and `npm run cf:build` passed on 2026-10-04; the Cloudflare build still emits the Node.js-middleware experimental-support warning.

### Open items / next pass

- This audit does not establish commercial display rights for every CEX provider, CoinGecko, GeckoTerminal, DexScreener, or risk vendor. Keep product/legal review open; free/keyless does not imply redistribution permission.
- Browser/region/CORS verification remains a matrix task. No provider should be described as universally available, complete, or production-grade based on local smoke results.
- In-browser per-source cooldowns and local request budgets cannot coordinate all visitors behind a shared upstream IP. The KuCoin route is a fixed-provider endpoint, not an arbitrary proxy, but its cache/rate controls are per isolate; distributed abuse/rate-limit hardening is still a separate server-side task.
- The production dependency audit is clean, but `npm audit` still reports 7 high findings in the Tailwind/ESLint glob-brace dependency chain. `npm audit` offers no compatible Tailwind 3 fix and suggests downgrading `eslint-config-next` to 14.2.35; keep migration open rather than force-downgrading Next's lint config.
- `npm run cf:build` passes with `compatibility_date` 2026-10-04. OpenNext still warns that Cloudflare Node.js middleware support is experimental. Actual deployment behavior and a supported-Node matrix remain unverified. Puppeteer browser installation previously failed because the Chrome download host disconnected during TLS; full browser E2E and `npm run qa:full` remain unrun.
- A fresh **offline** audit now exists at `RELEASE-AUDIT.md`: **445 PASS / 0 FAIL / 20 SKIP**. M1, deterministic offline fixtures (M11), local HTTP/SSR security baseline (M12) and the M7 Cloudflare build pass; browser-dependent M2–M6/M8–M10 are explicitly marked SKIP with reasons. This is not a full release approval. There is no root `AUDIT.md`. Re-run `npm run qa:full` only when Chrome and the required test environment are available. Remaining non-API items include GSC verification placeholders, best-effort donation unlock semantics, ads/browser coverage and provider-term review. The coverage/probe/screener claims were reviewed in README, localized FAQ and llms.txt, but future edits should preserve the same caveats. **NodeChart is the product; NodeCluster is only its support/resistance feature; Liq Radar is a separate feature.**
