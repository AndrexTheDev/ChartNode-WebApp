Userskripte – Schritt für Schritt

1
Skript schreibenSchreibe eine JavaScript-Funktion, die pro Kerze 'buy', 'sell' oder null zurückgibt. Dir stehen c (aktuelle Kerze inkl. Indikatoren), prev (vorherige Kerze) und all (alle Kerzen) zur Verfügung.
2
Einfügen oder von GitHub importierenFüge den Code direkt in das Textfeld ein, oder wechsle zu "GitHub-Raw-URL" und gib einen Link im Format raw.githubusercontent.com/... an.
3
Importieren & aktivierenKlicke "Skript importieren" - es erscheint in der Liste. Mit dem Toggle schaltest du die Buy/Sell-Marker direkt im Chart ein oder aus.
4
Mehrere Skripte kombinierenDu kannst beliebig viele eigene Skripte gleichzeitig aktiviert lassen - jedes bekommt seine eigene Marker-Farbe im Chart.
Einheitliches Code-Beispiel
// EMA 20/50 Golden Cross
if (!prev || !c.ema20 || !c.ema50) return null;
if (prev.ema20 <= prev.ema50 && c.ema20 > c.ema50) return 'buy';
if (prev.ema20 >= prev.ema50 && c.ema20 < c.ema50) return 'sell';
return null;
Skripte laufen ausschließlich lokal in deinem Browser - es werden keine Daten an einen Server gesendet.
